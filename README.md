# Список вещей - React приложение
### Простое React-приложение для управления списком вещей с возможностью добавления и удаления элементов.

## 🚀 Функциональность
```
📝 Отображение списка вещей
➕ Добавление новых вещей через форму
❌ Удаление вещей из списка
💾 Автоматическое сохранение в localStorage
🎨 Адаптивный и доступный интерфейс
⚡ Валидация форм с отображением ошибок
```

## 🛠 Технологии
```
React 18 - библиотека для построения пользовательских интерфейсов
TypeScript - статическая типизация
SCSS - стилизация с поддержкой вложенности
Custom Hooks - переиспользуемая логика (useLocalStorage)
```
## 📦 Установка и запуск
### Клонируйте репозиторий:
```
bash
git clone <repository-url>
cd items-list-app
```
### Установите зависимости:
```
bash
npm install
```
### Запустите приложение в режиме разработки:
```
bash
npm start
```
### Откройте http://localhost:3000 в браузере.
## 🏗 Структура проекта
```
src/
├── components/          # Компоненты приложения
│   ├── ItemCard.tsx    # Карточка отдельной вещи
│   └── AddItemForm.tsx # Форма добавления новой вещи
├── hooks/              # Кастомные хуки
│   └── useLocalStorage.ts # Хук для работы с localStorage
├── types/              # Типы TypeScript
│   └── index.ts        # Все типы приложения
├── App.tsx             # Главный компонент приложения
├── index.tsx           # Точка входа
└── index.scss          # Стили приложения
```
## 🧩 Основные компоненты
### App
```
Главный компонент приложения, управляет состоянием списка вещей и передает props дочерним компонентам.
```
### AddItemForm
```
Компонент формы с валидацией для добавления новых вещей:
- Проверка на пустое поле
- Визуальная индикация ошибок
- Автоматический сброс ошибок при вводе
```
### ItemCard
```
Компонент для отображения отдельной вещи с кнопкой удаления.
```
### useLocalStorage
```
Кастомный хук для синхронизации состояния React с localStorage.
```
